
## Créer une branche

Travaillez sur une branche dédiée, créée à partir de `main`.

Utilisez un nom court en minuscules, avec des mots séparés par des tirets :

Préfixes recommandés :

 `feature/` Nouvelle fonctionnalité 
 `fix/`  Correction de bug 
 `docs/`  Documentation 
 `test/`  Tests 
 `ci/`  Intégration ou livraison continue

## Formater les commits

Les messages suivent **Conventional Commits** :

Exemples :

```text
feat(api): ajouter le filtre par statut
fix(frontend): corriger le compte à rebours
docs: documenter les variables d'environnement
test(backend): couvrir les commandes sans stock
```

Types: `feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, `ci`, `chore` et `revert`
